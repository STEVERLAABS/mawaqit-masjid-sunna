# 🕌 مواقيت الصلاة — نسخة الهاتف

واجهة هاتف عربية (RTL) لعرض مواقيت الصلاة لمسجد السنة في المحمدية، مع إبقاء حساب المواقيت محلياً داخل المتصفح.

## ما الذي تغيّر؟

- تجربة **هاتف أولاً** ضمن واجهة بعرض تطبيق الهاتف، من دون وضع سطح المكتب أو التلفاز.
- بطاقة كبيرة للصلاة القادمة مع عدّاد حيّ.
- شبكة ثابتة من عمودين للمواقيت، مع بطاقات لمس واضحة.
- شريط تنقّل سفلي إلى: اليوم، المواقيت، جدول الشهر، والأذكار.
- تبويبات أذكار قابلة للتمرير أفقياً وعدّاد محفوظ على الجهاز.
- تقويم شهري قابل للتمرير أفقياً ونسخ أي يوم بلمسة.
- احترام المساحات الآمنة للشاشات الحديثة، ودعم تقليل الحركة.
- ملفات Manifest وService Worker لتخزين الملفات الأساسية محلياً بعد الزيارة الأولى على استضافة HTTPS.

## التشغيل محلياً

    python -m http.server 4173

ثم افتح:

    http://localhost:4173

## الإعدادات

عدّل ملف js/config.js فقط لتغيير:

- إحداثيات المسجد والمنطقة الزمنية.
- منهج الحساب والمذهب.
- توقيت الجمعة.
- ملف الأذان ومستوى الصوت.
- تنبيه الاستعداد قبل الأذان.

## النشر

المشروع ثابت بالكامل ويمكن نشره مباشرةً على GitHub Pages أو أي استضافة ملفات ثابتة. يفضَّل النشر عبر HTTPS كي يعمل التخزين المحلي وميزات تطبيق الويب.

> الأوقات تقريبية للتذكير؛ اعتمد أذان المسجد الرسمي.
